# 更新记录

## 1.7.0 — 2026-11-28

- 主聊天、桌宠聊天和「看进度」正常回复后，奶蛙会播放六个独立姿势的庆祝跳，再接回原动作。
- 桌宠聊天支持流式回复，并在读会话、搜索和阅读网页时显示对应状态。
- 刷新后可按会话翻阅聊天记录、预览图片并引用旧图继续追问。旧版已保存的文字记录可以继续读取。
- 「看进度」将工具调用与结果配对，显示失败步骤和末尾报错，支持展开命令和输出原文。
- 桌面端支持整框拖动，触屏支持滑动翻阅和长按拖动。消息和代码块可分别复制。

## 1.6.0 — 2026-11-26

- 配置面板新增「界面语言」，支持中文和 English，即时切换面板和桌宠聊天框，并记住选择。
- 移除配置面板的「回答语言」一栏。

## 1.5.0 — 2026-11-25

- 骑车动画增加到 8 帧。桌宠聊天框支持整框拖动、分段排版、粘贴和发送图片。
- 桌宠可以读取更早的当前会话记录，并通过 Harness 的只读联网工具搜索和读取网页。
- 回合结束提示音新增「嘎嘎滴辣虾」「卡脚塞」「齁辣干巴爹」，来自 [naiwa-studio](https://github.com/Theorists258/naiwa-studio/tree/main/public/audio)。连同已有四段合成音，共七段随机提示音。

## 1.4.0 — 2026-11-24

- 主对话新增奶龙人格。在面板选择「人格 → 奶龙」，或输入 `/naiwa strength 奶龙`，下一轮生效，重启后保留选择。
- 桌宠闲聊和「看进度」改用独立请求。新回复只显示在桌宠气泡里，主会话不再新增相关命令记录。已有桌宠记忆可继续使用。

## 1.3.0 — 2026-11-24

- 新增可选桌宠，支持骑车、芭蕾、蹦跳和捧腹大笑。点击桌宠会播放笑声并打开聊天气泡，背景和回合完成音效各自独立。
- 桌宠可通过当前会话的 DeepSeek 模型闲聊或查看项目进度。对话按会话保存在本机，重启后可继续；较早的对话按需压缩为摘要。
- 仓库首页使用随仓库分发的奶蛙桌宠预览图。

## 1.2.1 — 2026-11-23

- 显式声明 Web 面板用到的宿主模块，修复同页再次加载经典脚本时的重复声明错误。
- 会话切换时重新订阅当前会话的完成音效。

## 1.2.0 — 2026-11-21

- 更新人格文本与拟声词表，移除带「齁」的拟声。

## 1.1.0 — 2026-11-20

- **档位**：改为两档 `关闭 / 奶蛙`（旧值 `restrained` / `feral` 自动回落 `naiwa`）；面板只留两个 chip。
- **人格**：重写为四条精髓——抽象、与世无争、看破红尘、大笑着面对残酷世界的英雄主义；收尾同步。
- **艺术语法**：按四条精髓重写——梨形站姿、前突尖吻、小眼半睁、平嘴择时笑、裂痕补丁、留白偏置；美术池与中英提示词同步。
- **词典**：删除「失败作」「绷学」（35 → 33 条）。
- **拟声**：标志音改为「哟齁齁齁」＋空耳表，删除「呱」。
- **Web GUI**：控制条改为「● 奶蛙」胶囊 + 竖直面板；新增皮肤叠层（14 token）、音效开关、背景两态（站姿 / 捧腹大笑）。
- **背景**：顶层水印 `body::after`；常态站姿，播放音效时切大笑，音频结束/失败复原；右侧居中、52vh、底部渐隐，不遮挡输入框。
- **音效**：每轮回答完成随机播放 4 段（原版笑声 3 秒 + 嘎嘎滴辣虾 / 卡脚塞 / 齁辣干巴爹）。
- **整理**：一次性素材与脚本归档到 `references/archive/` 与 `scripts/archive/`；删除死代码。
